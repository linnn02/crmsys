# База данных

Источник истины — `prisma/schema.prisma` и SQL миграций. UUID идентификаторы, createdAt/updatedAt, внешние ключи Restrict и индексы на поисковые/связанные поля.

| Модель                            | Назначение и связи                                                       |
| --------------------------------- | ------------------------------------------------------------------------ |
| Role, User, Session               | Код роли, учётная запись, отзываемая сессия                              |
| Teacher                           | Профиль преподавателя, необязательная уникальная связь с User            |
| Student                           | Ребёнок, дата рождения, статус, примечания; возраст не хранится          |
| Parent, StudentParent             | Представители и M:N связь с детьми                                       |
| Course                            | Направление, возрастная категория, длительность                          |
| Group, GroupEnrollment            | Преподаватель, направление, лимит; интервалы пребывания ученика в группе |
| Room                              | Кабинет и вместимость                                                    |
| Lesson, RecurrenceRule            | Временной интервал, преподаватель, группа, кабинет; недельная серия      |
| Attendance, AttendanceHistory     | Единственная отметка ученик+занятие и история её изменений               |
| TariffPlan                        | Цена, лимит, срок и правила списания                                     |
| Subscription, SubscriptionHistory | Снимок тарифа, сроки/заморозка и история действий                        |
| SubscriptionUsage                 | Единственная запись на Attendance, reversedAt для восстановления         |

| Payment, PaymentAllocation        | Факт поступления и распределение на счёт                                 |
| Refund                            | Отдельная корректирующая операция, не удаление Payment                   |
| Notification                      | Внутренние уведомления конкретному пользователю                          |
| AuditLog                          | Актор, операция, тип и ID сущности, безопасные детали                    |

## Финансовая модель

Суммы Decimal(14,2), цены приобретённых абонементов не зависят от дальнейшего изменения тарифа. В текущем API каждый Payment связан с одним Invoice через PaymentAllocation. Долг = начисление − распределённые платежи + возвраты. Возврат ограничен невозвращённой частью платежа. Поступления и начисления показываются раздельно. В финансовых сервисах вычисления выполняет Prisma.Decimal.

## Ограничения PostgreSQL

1. Уникальные email пользователей/преподавателей, телефон представителя, пара ФИО+дата рождения ребёнка, названия справочников.
2. Частичный уникальный индекс Student+Group для активной записи (`leftAt IS NULL`).
3. Уникальная пара Attendance.studentId+lessonId и уникальный SubscriptionUsage.attendanceId.
4. CHECK для положительных денег/вместимости/лимитов и правильного времени.
5. `btree_gist` и EXCLUDE для непересекающихся интервалов преподавателя, кабинета и группы; отменённые занятия исключены из ограничений.
6. Финансовые и исторические таблицы защищены триггерами от UPDATE/DELETE. Эти PostgreSQL-триггеры не выражаются средствами Prisma schema, поэтому сохраняются именно в SQL миграции.

## История

Обычные API не удаляют студентов, преподавателей и группы физически. Архивирование ученика завершает активные записи в группы, сохраняя связанные посещения и финансы. AttendanceHistory и SubscriptionHistory фиксируют изменения. Отмена занятия восстанавливает его списания через reversedAt. Права пользователя БД должны исключать обход этих правил в рабочем окружении.

## Особенности

Проверка дубля ФИО+дата рождения намеренно строгая и может потребовать доработки для реальных полных тёзок. Взаимоотношение ребёнка с представителем редактируется заменой текущих связей; детальная история этих связей пока не реализована.
