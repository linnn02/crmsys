# Руководство пользователя

1. Войдите по email и паролю, выданным администратором. Главная показывает разрешённые для роли показатели. Сессия действует до 8 часов.
2. Начните с представителей: Родители → Добавить. Затем Ученики → Добавить, заполните ФИО/дату рождения и выберите одного или нескольких представителей (Ctrl при выборе нескольких на ПК).
3. Откройте ученика по имени. Здесь доступны контакты, группы, посещения и финансовая история. Выберите группу и нажмите «Записать». При отсутствии места сервер объяснит причину отказа.
4. Преподавателей добавляет администратор. Для входа преподавателя сначала создайте пользователя с ролью TEACHER в Настройках, затем привяжите его к профилю преподавателя.
5. В Настройках создаются направления, кабинеты и тарифы. Тариф с пустым лимитом занятий — безлимитный. Отменённые занятия в текущей версии всегда восстанавливают списания; настройка платной отмены не включена.
6. В Расписании нажмите «Создать занятие». Все поля времени — Алматы. Для серии укажите число повторений и интервал недель. Щелчок по занятию открывает редактирование; выбор области задаёт одно занятие или запланированную часть серии. «Отменить занятие» требует подтверждения.
7. Посещаемость доступна для начавшихся занятий. Выберите занятие, отметьте учеников и сохраните. По умолчанию новые отметки в форме — «Присутствовал»; проверьте весь список перед сохранением. Учитель видит только назначенные ему занятия.
8. В Абонементах выберите ученика, группу, тариф и начало. Счёт появится автоматически. Заморозка приостанавливает выбор абонемента для новых списаний, возобновление продлевает срок на время заморозки. «+7 дней» — административное продление срока без новых занятий и без новой платы.
9. В Платежах выберите счёт, сумму и способ. Допускается частичная оплата; переплата отклоняется. Зарегистрированный платёж означает запись сотрудника, а не подтверждение банка. Для исправления используйте «Возврат» и укажите причину. PDF-квитанция доступна в истории оплат, CSV — в заголовке раздела.
10. Уведомления показывают изменения расписания и напоминания. «Прочитано» меняет только ваше уведомление. Финансовые напоминания вычисляются при открытии центра уведомлений.
11. Архивируйте ушедших учеников кнопкой в списке. Финансовая история сохраняется. Создание, редактирование роли и пароля, отключение пользователя доступны администратору. При смене роли/пароля сессии отзываются; собственную запись отключить или понизить нельзя. Связанный профиль преподавателя требует сохранения роли TEACHER.

## Роли

Администратор управляет всеми разделами. Менеджер ведёт клиентов, группы, календарь, посещения и финансы; не создаёт сотрудников, тарифы или роли. Преподаватель работает со своими учениками, занятиями и посещаемостью; финансовых ответов API не получает.

## Ошибки

«Недостаточно прав» — обратитесь к администратору. «Такая запись уже существует» — сначала найдите существующую запись. Конфликт расписания — измените время, кабинет или преподавателя. Если сервер недоступен, используйте «Повторить» после восстановления соединения; не повторяйте финансовое действие с новым ключом, пока не проверите историю операции.
