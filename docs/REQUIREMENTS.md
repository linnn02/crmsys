## Нефункциональные требования

TypeScript strict, один PostgreSQL, модульный монолит. Секреты только через окружение. Сервер проверяет роль и принадлежность данных. Суммы Decimal(14,2); API передаёт денежные значения строками. Границы занятий [start,end), даты timestamptz, отображение Asia/Almaty. Seed не содержит реальных персональных данных. Изменяющие операции защищены транзакциями, ограничения дополняются уникальными индексами и CHECK/EXCLUDE в PostgreSQL.

## Производственные границы

Не проводились нагрузочное тестирование, независимый аудит безопасности и тест восстановления инфраструктуры. Rate limit в памяти рассчитан на один API-процесс. История всех пользовательских действий не является системой расследований: аудит фиксирует критические бизнес-операции, без хранения паролей или токенов.
