# Сценарии использования

## UC-01: Вход

Сотрудник вводит email/пароль. API проверяет Argon2id, создаёт сессию и cookie, интерфейс открывает Dashboard. Неверные данные возвращают 401. Чужая роль не принимается от клиента.

## UC-02: Новый клиент

Менеджер создаёт представителей, затем ученика с датой рождения и выбранными представителями. Сервер проверяет уникальность и существование родителей. Карточка показывает возраст, контакты, группы и историю. Для преподавателя финансовая часть исключена из ответа API.

## UC-03: Запись в группу

В карточке ученика менеджер выбирает группу. Сервер проверяет статус, активную запись и свободное место в сериализуемой транзакции. При переполнении возвращает 409. Отчисление устанавливает leftAt.

## UC-04: Серия занятий

Сотрудник выбирает группу, преподавателя, кабинет и начало/конец, задаёт число повторений и интервал недель. Вся серия создаётся атомарно. Конфликт хотя бы одного занятия откатывает серию. При редактировании выбирается одно занятие или все запланированные занятия серии; завершённая история не переносится.

## UC-05: Посещаемость

Преподаватель выбирает своё прошедшее занятие и отмечает список. Сохраняется история изменений. По правилам абонемента создаётся не более одного списания на посещение. Повтор той же отметки не тратит ещё одно занятие. Исправление на уважительный пропуск возвращает занятие, если тариф не списывает такой пропуск.

## UC-06: Абонемент и оплата

Менеджер выдаёт абонемент: фиксируются цена/правила и создаётся счёт. По счёту можно внести часть суммы. Повтор того же запроса с тем же ключом возвращает тот же Payment. Ошибка оплаты исправляется возвратом с причиной; исходный платёж сохраняется. Квитанция PDF явно обозначает ручной источник.

## UC-07: Заморозка

Сотрудник замораживает действующий абонемент. Новые списания по замороженному абонементу не выбираются автоматически. Возобновление сдвигает окончание на длительность заморозки. Продление кнопкой +7 дней меняет срок, но не выдаёт новые занятия и не выставляет новый счёт.

## UC-08: Архив

Сотрудник подтверждает архивирование ребёнка. Текущие записи в группы завершаются, посещаемость, абонементы, счета и платежи сохраняются. Операция попадает в аудит.
