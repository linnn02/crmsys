# Сверка с требованиями Ugusha

| Область | Статус | Текущее состояние |
|---|---|---|
| Авторизация и RBAC | Реализовано | JWT, Argon2id, серверные проверки ролей, роли администратора, менеджера, преподавателя и курортной команды |
| Ученики и родители | Частично | CRUD, несколько представителей, архивирование и история есть; рост, размер ноги и уровень катания уже есть в Prisma/API, но frontend-формы карточки и регистрации требуют доработки |
| Активности курорта | Частично | Активности, площадки, бронирования, согласия и инвентарь есть; нет полного прокатного журнала и статусов визита |
| Расписание и слоты | Частично | FullCalendar, серии и конфликты есть; нет смен сотрудников, drag-and-drop и отдельного онлайн-слота |
| Запись ребёнка из расписания | Отсутствует | Есть отдельный API бронирований, но нет формы записи прямо из календаря и овербукинга с подтверждением |
| Ротация | Отсутствует | История групп есть, отдельной операции ротации ребёнка между инструкторами и слотами нет |
| Оператор проката | Частично | Роль `CLUB_OPERATOR` добавлена, но нужно ограничить редактирование только прокатными данными |
| Онлайн-запись | Частично | Локальный `POST /api/public/activity-bookings` и экран `/online-booking` создают/находят гостя, ребёнка, согласие и бронь в одной транзакции; API-тесты и полноценная пользовательская проверка ещё нужны |
| Кассовый адаптер | Отсутствует | Ручные платежи есть; контракт внешней кассы и callback нужно добавить без заявления о реальной интеграции |
| Зарплата | Отсутствует | Ставки, категории, ведомость и закрытие периода не реализованы |
| Аудит | Частично | Критические учебные и финансовые действия пишутся; новые операции проката, ротации и зарплаты нужно расширить |
| Отчёты | Частично | Платёжный CSV и dashboard есть; нужны отчёты по загрузке, инструкторам, онлайн-записям, оборудованию и зарплате |

Мобильное приложение, PWA, Capacitor и публикация в App Store/Google Play не входят в объём работ.
