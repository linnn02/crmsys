# Техническое задание

Тема: «Разработка CRM-системы для детского центра с функциями учёта клиентов, расписания занятий и оплаты».

## Назначение

Единое рабочее пространство небольшого образовательного центра. Пользователи — администратор, менеджер и преподаватель. Родительский личный кабинет и эквайринг в текущую версию не входят.

## Целевая функциональность

Учёт детей и представителей, преподавателей, направлений, групп, расписания, посещаемости, абонементов, начислений, поступлений, возвратов и уведомлений. Все операции, относящиеся к бизнес-данным, сохраняются в PostgreSQL.

## Реализованный объём

Подробный перечень работающих сценариев — README и USE_CASES. В текущей реализации абонемент приобретается для группы; один платёж распределяется на один счёт. Повторения поддерживают недельный интервал и число повторений до 52. Сессия ограничена 8 часами, после истечения требуется повторный вход. История финансов защищена append-only триггерами.

## Критерии приёмки

Успешная сборка frontend/backend, применение миграций и seed, запуск на PostgreSQL, прохождение тестов авторизации, RBAC, клиентов, расписания, посещаемости и финансов. Полная приёмка требует также фактического запуска Docker Compose и закрытия оставшихся пунктов PROJECT_PROGRESS.

## Ограничения текущей версии

Фильтры финансов/аналитики и смена ролей/паролей реализованы. Привязка абонемента только к направлению, расширенная отчётность, полная i18n и эксплуатационные проверки требуют завершения. Наличие каталога документации не означает завершения этих функций. Документ отражает MVP, а исходный запрос пользователя остаётся целевым расширенным ТЗ.
